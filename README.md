# DID Wallet Thesis

Bachelor's thesis project implementing a complete Self-Sovereign Identity (SSI) ecosystem using Decentralized Identifiers (DIDs) and Verifiable Credentials.

## Project Structure

- **mobile-wallet/** - Holder wallet (React Native + Veramo)
- **verifier-app/** - Credential verification application (TBD)
- **issuer-platform/** - Credential issuance platform (TBD)

## Technologies

- React Native + Expo
- Veramo Framework
- cheqd Network
- W3C DID & VC Standards

## Mobile Wallet Features (v0.1)

✅ DID Creation (did:key method)  
✅ Ed25519 Key Management  
✅ DID Resolution  
✅ SQLite Persistent Storage  
✅ DID Document Inspection
